# Profile artwork

The two SVG headers are original graphics for this profile. Signals travel through a connection diagram; the name and introduction stay still. CSS animations stop for `prefers-reduced-motion: reduce`.

Typography:

- **Geist Sans SemiBold** for the name and **Geist Mono Regular** for the label — [Vercel / Geist](https://vercel.com/font), [source and SIL Open Font License](https://github.com/vercel/geist-font).
- **Pretendard Medium** for the Korean line — [Pretendard](https://github.com/orioncactus/pretendard), SIL Open Font License.

The visible letters are vector outlines, so visitors do not need the fonts installed. The SVGs contain no scripts, embedded pages, external fonts, or remote image requests. Accessible names are supplied through SVG titles and the README image's alt text. The rest of the README remains native text.
